# pizza_SQL_Project

This project focuses on analyzing pizza sales data using SQL to understand sales performance, customer ordering patterns, popular pizza types and revenues distribution. 

The analysis involves joining multiple tables, applying aggregate functions, filtering, grouping, sorting, and using subqueries to extract meaningful business insights.


We have 4 tables as follow:

pizzas

pizza_types

orders

order_details

The dataset consists of 4 tables:

1.  Orders

order_id

date

time

2. order_details

order_details_id

order_id

pizza_id

quantity

3.pizzas

pizza_id

pizza_type_id

size

price

4. pizza_types

pizza_type_id

name

ingrredients
